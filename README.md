
# 🌤️ Weather App

A simple and responsive weather application built using Javascript.
 This app allows users to search for a city and view the current weather details such as temperature,
condition, humidity, and more — all fetched from a public weather API.

## 🚀 Features

- 🌍 Search for any city worldwide
- 🌡️ View current temperature, humidity, and weather conditions
- 📱 Fully responsive design
- 🔄 Auto updates based on search

## 🛠️ Technologies Used

- HTML/CSS
- JavaScript (ES6+)
- OpenWeatherMap API (or your chosen weather API)
- Axios or Fetch API for HTTP requests


## 🧪 How to Run the Project Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/weather-app.git
   cd weather-app
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Add your API key**
   - Create a `.env` file in the root.
   - Add your API key like:
     ```
     APP_WEATHER_API_KEY=your_api_key_here
     ```

4. **Start the application**
   ```bash
   npm start
   ```

5. Visit `http://localhost:3000` in your browser.
